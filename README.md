# 🎨 고등학교 미술 수업 아트보드 & 세특 관리 시스템 (ArtBoard)

고등학교 미술 수업에서 학생들이 창작한 미술작품을 패들렛(Padlet) 형태로 공유하고, 교사용 관리자 모드에서 학생의 작품과 작가노트를 분석하여 **학교생활기록부 '과목별 세부능력 및 특기사항(세특)'**을 자동 생성 및 엑셀(.xlsx)로 다운로드할 수 있는 웹 애플리케이션입니다.

---

## 🌟 주요 기능

### 1. 학생용 협업 갤러리 보드 (패들렛 스타일)
- **반별 독립 페이지 분리**: 각 반(1반, 2반, 3반, 4반 등)마다 고유한 보드가 제공되어 같은 반 친구들끼리 서로의 작품을 감상하고 교류할 수 있습니다.
- **QR코드 스마트폰 초간편 접속**: 교실 빔프로젝터나 TV에 띄운 반별 QR코드를 학생 스마트폰 카메라로 스캔하면 즉시 접속됩니다.
- **학번 및 이름 입장 게이트**: 접속 시 학번(예: `10101`)과 이름(예: `김민수`)을 입력하면 브라우저에 기억되어 간편하게 활동할 수 있습니다.
- **스마트폰 촬영 & 실시간 이미지 최적화**: 
  - 카메라로 직접 촬영하거나 갤러리에서 사진 첨부 가능.
  - 고용량 원본 사진을 브라우저에서 자동으로 고화질 압축(최대 1280px Web Optimized JPEG)하여 빠른 속도와 데이터 절약을 보장합니다.
- **작품 제목 및 세부 작가노트 작성 칸**:
  - 발상 동기, 조형 기법(색채/구도/재료), 전하고 싶은 메시지를 입력할 수 있는 친절한 가이드 제공.
- **친구들의 인터랙션**: 좋아요(❤️) 및 응원 한마디(💬) 댓글 기능.

---

### 2. 교사용 관리자 모드 & AI 세특 분석 평가
- **비밀번호 보호**: 교사만 접근 가능한 관리자 모드 (기본 비밀번호: `1234`, 설정에서 변경 가능).
- **교육부 훈령 및 학교생활기록부 기재요령 준수**:
  - 개조식/명사형 종결 배제, 완성형 서술어 종결(`~함.`, `~을 구현함.`, `~역량이 돋보임.`).
  - 미술과 4대 핵심 영역(발상 및 주제의식, 조형요소 및 표현기법, 시각소통 및 예술적 메시지, 수업태도 및 미적 성장) 종합 분석.
- **5가지 세특 문체 프리셋 지원**:
  1. 🎨 종합 균형형 (발상 + 기법 + 소통 + 태도 표준)
  2. 🖌️ 조형요소 및 표현기법 중심 (재료, 마티에르, 테크닉 강조)
  3. 💡 창의적 발상 및 독창성 중심 (참신한 시각, 개성 표현 강조)
  4. 🔍 주제의식 및 비평적 시각 중심 (사회·철학적 메시지, 시각소통 강조)
  5. 🌿 미적 감수성 및 내면 성찰 중심 (자아 탐색, 서정적 분위기 강조)
- **실시간 NEIS 바이트 계산기**: 한글 3바이트 기준, NEIS 1,500바이트 제한 실시간 카운트 및 원클릭 복사(📋) 지원.
- **일괄 자동 생성**: 클릭 한 번으로 반 전체 학생의 세특을 순식간에 일괄 생성.
- **선택적 Google Gemini API 연동**: 설정창에서 Gemini API 키를 넣으면 최신 생성형 AI 모델로 더욱 세밀한 맞춤형 비평 세특을 생성할 수 있습니다 (API 키 없이도 내장 분석 엔진으로 100% 완전 오프라인 작동).

---

### 3. 엑셀 다운로드 (나이스 업로드 양식)
- **원클릭 `.xlsx` 다운로드**: 별도의 오피스 프로그램이나 외부 서버 없이 브라우저에서 직접 생성.
- **정리된 컬럼 구성**:
  `[연번, 학년반, 학번, 성명, 작품 제목, 작품 내용 및 작가노트, 과목별 세부능력 및 특기사항(세특), NEIS 바이트수, 제출 일시]`
- 반별 다운로드 및 전체 반 통합 다운로드 지원.

---

### 4. 수업 빔프로젝터용 대형 QR 안내 모드
- 칠판이나 TV 화면에 크게 띄울 수 있는 대형 QR코드 모드 지원.
- 학생 안내 순서(1. 카메라 스캔 2. 학번/이름 입력 3. 작품 사진과 설명 등록)가 큰 글씨로 함께 표시됩니다.
- 인쇄 버튼 클릭 시 A4 용지 출력 레이아웃 자동 적용.

## 🚀 실행 방법

### 방법 1: 로컬 웹 서버 실행 (가장 추천 - 교실 Wi-Fi 내 실시간 공유)
1. 폴더 내 `run.bat` 파일을 더블 클릭합니다.
2. 검은색 콘솔 창이 뜨면서 교사용 주소(`http://localhost:8080/`)와 학생 접속용 스마트폰 주소(`http://[선생님PC-IP]:8080/`)가 표시되며 브라우저가 자동으로 열립니다.
3. 상단의 **[📱 QR코드 안내]** 버튼을 눌러 교실 화면에 띄우면, 같은 학교 Wi-Fi에 연결된 학생들이 스마트폰 카메라로 QR을 찍고 바로 작품을 올릴 수 있습니다!
4. 등록된 작품은 `data/posts.json`에 안전하게 자동 저장됩니다.

### 방법 2: 무설치 단독 실행 (오프라인 / 시연용)
- `public/index.html` 파일을 Chrome이나 Edge 브라우저로 바로 열어도 모든 기능(보드, QR생성, 세특 자동 생성, 엑셀 다운로드)이 로컬 브라우저 저장소(LocalStorage)를 통해 정상 작동합니다.

## 📁 프로젝트 구조

```
art-padlet/
├── run.bat              # 교사용 1-클릭 서버 실행 배치 파일
├── server.ps1           # 윈도우 기본 탑재 PowerShell 고성능 HTTP 서버
├── README.md            # 사용 설명서
├── data/
│   ├── classes.json     # 반 정보 데이터베이스
│   └── posts.json       # 학생 작품 및 세특 평가 데이터베이스
└── public/
    ├── index.html       # 메인 웹 페이지 (학생 갤러리 + 교사 관리자 모드)
    ├── app.js           # 프론트엔드 로직 & AI 세특 생성 엔진 & 엑셀/QR 생성기
    ├── style.css        # 디자인 및 인쇄용 스타일시트
    └── vendor/
        ├── qrcode.min.js     # QR코드 생성 라이브러리
        └── xlsx.full.min.js  # 엑셀(.xlsx) 생성 라이브러리
```
